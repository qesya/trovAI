# TrovAI brand assets

## File

- `trovai-logo-primary.png` — logo orizzontale principale, sfondo trasparente.
- `trovai-wordmark.png` — solo scritta, sfondo trasparente.
- `trovai-icon.png` — simbolo quadrato per avatar, app icon e favicon sorgente.
- `trovai-logo-dark.png` — logo orizzontale ottimizzato su fondo navy.

## Colori

- Bordeaux principale: `#681D35`
- Pesca principale: `#FFB38A`
- Bordeaux di sfondo: `#3A1020`
- Crema di sfondo: `#FFF8F3`
- Bianco per variante scura: `#FFFFFF`

## Uso

- Lasciare intorno al logo uno spazio libero almeno pari all'altezza della lettera
  `o` del wordmark.
- Non deformare, ruotare, ricolorare o aggiungere ombre.
- Usare il logo principale su fondi chiari o neutri.
- Usare `trovai-logo-dark.png` come asset completo sui materiali scuri.
- Usare l'icona senza wordmark quando lo spazio orizzontale e limitato.

Gli asset sono raster PNG. Per stampa, grandi formati o registrazione del marchio e
consigliabile far ridisegnare il logo in SVG vettoriale da un designer, usando
questi file come riferimento approvato.
